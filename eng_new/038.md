There are six core States: Mad, Sad, Scared, Joyful, Powerful, and
Peaceful. From each of these core emotions, almost anything that a
character is feeling can be extrapolated. A feeling wheel follows to illustrate
the point, and is part of the reference sheets along with basic moves,
playbooks, and other handouts.

correlate to one another. The playbook handouts themselves show you

feeling in any given scene when a move is triggered.
