ТИПЫ УРОНА

Типы урона нужны только для того, чтобы объяснить, какой именно урон наносится в вымысле. Каждый раз, когда что-либо наносит n урона, где n — число нанесённого урона, это также может быть тегом типа урона. Оно всё равно всегда наносит ровно столько урона, сколько ему назначено, но теперь в вымысле понятно, как этот урон выглядит. Если у оружия не указан тип урона, значит, оно используется в обычном смысле и не требует уточнения через тип урона.

ФЛЕШЕТТЫ: Выпускает россыпь маленьких дротиков, предназначенных для повреждения или отравления.

КИНЕТИЧЕСКИЙ: Выпускает волну силы.

ШОКОВЫЙ: Высвобождает электрическую энергию, вмешивается в работу нервной системы.

ОБЖИГАЮЩИЙ: Высвобождает тепловую энергию.

ПЛАЗМЕННЫЙ: Высвобождает сверхгорячую плазменную энергию.

ПУЧКОВЫЙ: Выпускает луч, состоящий из частиц.

МАГНИТНЫЙ: Использует магнитные силы, чтобы разогнать какой-либо снаряд.

ВЗРЫВНОЙ: Высвобождает огромное количество энергии и обычно сопровождается сильным шумом и высокими температурами.

ИСКАЖАЮЩИЙ: Тип урона, который резко ускоряет снаряд. Также может применяться к технике, которая вмешивается в работу чего-то ещё.

ЭМИ: Электромагнитный импульс; на некоторое время выводит из строя большинство электрических устройств.
