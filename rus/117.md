- Место, чтобы вписать кибернетику персонажа, если она есть.

Место для кибернетики нужно, чтобы игрок описал любые кибернетические улучшения, с которыми персонаж начинает игру, и рассказал, как он их получил. В зависимости от выбора игрок может детализировать этот элемент кибернетики, назначив ему несколько тэгов тегов, равное числу в скобках. Наконец, у каждого элемента кибернетики обязательно должен быть один отрицательный тег.

- Раздел, где перечислены особые ходы, с которыми персонаж начинает игру и которые может получить в дальнейшем в процессе развития.

Раздел с особыми ходами персонажа находится справа. Рядом с каждым ходом есть кружок. Если кружок уже отмечен по умолчанию, значит персонаж начинает игру с этим ходом; такой ход вполне уместно называется стартовым. Ниже перечислены ходы с пустыми кружками — их можно получить позже, когда персонаж накопит достаточно опыта, чтобы вырасти и продвинуться дальше.
