- Место, где можно вписать кибернетику персонажа, если она есть.

Место для кибернетики нужно, чтобы игрок описал любые кибернетические улучшения, с которыми персонаж начинает игру, и рассказал, как он их получил. В зависимости от выбора игрок может детализировать этот элемент кибернетики, назначив ему количество тегов, равное числу в скобках рядом с ним. Наконец, у каждого элемента кибернетики обязательно должен быть один негативный тег.

- Раздел, где перечислены особые ходы, с которыми персонаж начинает игру и которые может получить через развитие.

Раздел с особыми ходами персонажа находится справа. Рядом с каждым ходом есть кружок. Если кружок уже отмечен по умолчанию, значит персонаж начинает игру с этим ходом; такой ход вполне уместно называется стартовым.
