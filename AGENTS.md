Задача проекта - перевод правил ролевой игры с английского на русский язык.

# Инструкции для переводов

- Используй все термины из файла `/Термины.md`
- Всегда переводи имена на русский язык (через привычную русскую форму или транслитерацию).
- Удаляй из итогового текста служебные/битые символы, включая `` `` `` и т.п..
- Если в исходнике есть игровые термины и механики, сохраняй их смысл и числовые значения.


# Структура проекта
/eng - тут лежат исходные тексты на английском разбитые на отдельные страницы. эти файлы менять нельзя.
/rus - сюда складывается текущий рабочий перевод, по имени соответствуя листам из /eng
